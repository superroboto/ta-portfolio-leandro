100K GPU Frogs: High-Performance Niagara Ambient Swarms

This project goes over how I made a highly optimized, scalable ambient wildlife system using GPU Niagara systems and material-driven WPO vertex animation. By shifting the animation from skeletal meshes to simple vertex shaders, the system handles massive entity counts at minimal cost.

Swarm Breakdown

The system manages three distinct animal behaviors

Frogs (GPU): Driven via a custom Niagara module for jumping behavior. Poses blend smoothly between idle and jumping states using the vertex shader.

Rats (GPU): Programmed to scurry dynamically across surfaces using Global Distance Fields while avoiding the player. A custom module calculates angular velocity to procedurally twist the body along its path during tight turns.

Fireflies (CPU): Unlike the GPU swarms, the fireflies utilize a CPU system to support light components for environmental illumination (no shadows).

Optimization & Custom LOD System

While originally created for low-density ambient life, I wanted to stress-test the scalability of these systems and address the performance bottlenecks associated with high instance counts (specifically mesh complexity).

To achieve this, I built a per-instance Niagara Level of Detail system to swap instances dynamically based on camera distance.

Performance Metrics

Tested on a mid-range Radeon RX 5700 at 1080p

Baseline (20,000 Frogs without LODs): 3.9ms frame time (bottlenecked by dense geometry).

Optimized (20,000 Frogs with LODs): 1.0ms frame time (a ~74% reduction in rendering overhead).

Stress Test Extreme (100,000 Frogs with LODs): 4.2ms frame time, proving extreme scalability on mid-range hardware. Performance would be even better if the frogs were less densely contained within a small area.

Future optimization

If the goal was actually massive 10k+ swarms, future iterations of this system would focus on

LOD Improvements: Dynamically disabling the frogs' WPO evaluation by swapping materials when instances enter a completely idle state.

Shader Cost Reduction: Adding the LOD logic to the Rats and further tweaking the lod levels.

Firefly Light Culling: Mitigating CPU costs by restricting light generation to a small percentage of the active swarm, and fading those light components out over distance.

Overdraw Mitigation: Implementing distance-based opacity fading and culling on the additive firefly glow sprites to minimize pixel overdraw.
