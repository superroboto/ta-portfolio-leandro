Nordic Island Creation Pipeline

Using my custom Nordic island creation pipeline, I was able to create, texture, and populate this entire island environment in just 1 hour (excluding prop placement).

I was also responsible for all lighting, the dynamic ocean system, and color grading to establish the final atmospheric mood.

1. Island Mesh Creation

Island creation timelapse

The pipeline starts with a low-fidelity, rapid base sculpt. A custom Blender Geometry Nodes modifier, ConvertToIsland, then handles the heavy lifting, procedurally generating high-frequency rock details, fracture lines, sediment layers, and macro ground variation.

  • One Mesh: By generating the island as a single mesh rather than kitbashing separate rock assets, geological layer lines remain perfectly seamless across the island.
  • Scalability: Built with Nanite in mind, though the setup can be baked down and split for traditional LOD systems.

2. Island Auto-Material

Once imported into Unreal, a procedural material automatically handles complex texturing, using vertex painting to define grassy areas.

  • To break up the "digital" look, the material features subtle world-coordinate offsetting to mimic realistic tectonic tilting.
  • The material samples a Runtime Virtual Texture (RVT) for dynamic path masking.

3. PCG and Splines

Foliage and secondary detail rocks are procedurally populated using PCG graphs driven by simple splines, maximizing runtime performance by spawning smaller assets directly on the GPU.

  • Foliage Mask Spline: Explicitly excludes rocks and grass within its volume (ideal for clearing out space for houses, landmarks, and props).
  • Grass Region Spline: Defines the bounds of the core grass and small rock distribution.
  • Path Spline: Automatically clears out grass instances and blends the underlying landscape material via RVT data.
  • Shore Rocks Spline: Spawns appropriate rock types along the island's shore.

4. Final Set Dressing

With the foundational landscape and ecological systems automated, I am free to focus entirely on high-level composition, set dressing, and prop placement.
