Flat-Surface 3D Sinkhole with Character & Physics Simulation

A dynamic 3D sinkhole rendered as a completely flat 2D plane, featuring rigid-body simulation for fracturing and ragdoll physics.

The system utilizes a true 3D mesh. To keep performance cost extremely cheap, no Custom Depth, stencil masks, or other post-process tricks are used. Instead, the effect is achieved entirely within the hole and character materials using vertex offsets and an opaque masked surface.

The video below demonstrates how the sinkhole and everything in it is rendered as if it were a completely flat plane.

Designed to Work Anywhere

A primary engineering goal was ensuring this system could be dynamically deployed in any game environment without requiring destructive workflow modifications.

Zero Terrain Reliance

It can be spawned anywhere in the world without requiring runtime geometry fracturing or changes to the underlying landscape.

Precision Spawning

The sinkhole system automatically spawns a mere 0.1cm above the existing surface mesh.

Vertical Isolation

Because it is entirely self-contained, it can be deployed on the second floor of a building while players on the floor directly beneath see absolutely nothing abnormal.

1. Seamless Blending

Upon initial spawning, the system captures a one-time, top-down orthographic projection of the ground context and writes it immediately to a dynamic Render Target.

2. Setting Up the Cover Mesh

This captured environment texture is projected onto a pre-fractured "ground" surface cover mesh. This creates a flawless visual match with the surrounding world materials right before the collapse sequence triggers.

3. Progression of the Fracture

When triggered, the pre-fractured cover mesh collapses, a niagara system creates small falling debris and a separate collision channel is used on the characters, allowing players to dynamically fall into this "fake" hole.

Material Functions & Viewmodes

The entire system is built around a tightly managed set of material functions mapping masks, vertex translations, and texture captures seamlessly together.
